# 统一显示设置设计

## 目标

桌面悬浮交通灯和 macOS 状态栏交通灯共用一套外观与提醒偏好，不再分别维护显示差异。

## 全局设置

| 设置 | 统一行为 |
| --- | --- |
| Layout | 两处同时使用 Vertical 或 Horizontal，红黄绿顺序一致。 |
| Size | 状态栏图标按所选 Small、Medium、Large、Extra Large、Huge 与悬浮灯同比例缩放；系统状态栏高度是唯一上限。 |
| Background | Black 时两处均显示黑色圆角外壳；Transparent 时两处均不显示外壳。 |
| Green Light Alert | Never、1、3、5、10 次为统一选项；两处同时按所选次数闪烁。 |

## 独立开关

`Show Floating Light` 仅决定桌面悬浮灯是否显示。状态栏交通灯始终保留，作为固定任务状态提示与设置入口。

## 实现约束

- 继续使用单一份 `UserDefaults` 偏好作为状态来源。
- 菜单栏和悬浮灯均监听同一份偏好变化，并立即重绘。
- 状态变更在闪烁期间到达时，两个显示位置都必须同步取消旧提醒。

## 验证

- 在每种布局、背景和尺寸下检查两处形状、颜色和红黄绿顺序一致。
- 切换每个绿灯提醒次数，确认两处闪烁次数一致且重启后设置保留。
