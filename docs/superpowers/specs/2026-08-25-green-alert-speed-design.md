# 绿灯提醒速度设计

## 目标

为绿灯完成提醒提供独立速度档位，使用户可在不改变闪烁次数的情况下调慢或调快提示节奏。

## 设置

菜单栏与悬浮灯右键菜单均提供 `Alert Speed`：

| 档位 | 每次亮或灭的时长 |
| --- | --- |
| Fast | 0.16 秒 |
| Normal | 0.30 秒 |
| Slow | 0.50 秒 |

默认档位为 `Slow`。

## 行为

- `Green Light Alert` 决定闪烁次数；`Alert Speed` 决定每次亮灭的时长。
- 两处显示共用同一份速度设置，并同时开始、同时结束。
- 任务重新开始时，仍立即取消当前提醒。
- 选择即时生效并在重启后保留。
