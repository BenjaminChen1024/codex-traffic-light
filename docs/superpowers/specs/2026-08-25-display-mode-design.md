# 显示位置切换设计

## 目标

Lights 只显示一份状态提示，并可在桌面悬浮交通灯和 macOS 菜单栏交通灯之间切换。切换不会改变现有 HTTP Hook、红黄绿状态映射、尺寸或排列设置。

## 交互

- 在右键菜单和菜单栏菜单增加“显示位置”。
- “桌面悬浮”：显示可拖动的悬浮交通灯；菜单栏保留应用入口图标。
- “菜单栏”：隐藏悬浮窗口；菜单栏图标改为当前红、黄或绿的交通灯状态图标。
- 选择立即生效，并保存为下次启动时的默认显示位置。
- 菜单栏模式下仍可从菜单切回桌面悬浮，且保留设置、关闭灯和退出操作。

## 实现边界

- 使用 `UserDefaults` 保存 `lightsDisplayMode`，取值为 `floating` 或 `menuBar`。
- `AppDelegate` 负责在模式变化时显示或隐藏现有窗口。
- `MenuBarController` 订阅 Lights 的状态变化和显示位置变化，重绘菜单栏图标；状态图标用三格交通灯表现，当前状态对应的灯点亮。
- 状态服务器仍是唯一状态来源：`executing` 为红、`permission` 为黄、`idle` 为绿。
- 桌面悬浮模式的窗口布局、尺寸、拖动位置与既有行为保持不变。

## 异常与验证

- 没有保存偏好时默认桌面悬浮，保证升级后与现在一致。
- 即使窗口被隐藏，状态服务器和菜单栏控制器仍继续运行。
- 手动验证：分别在两种显示位置下发送 red/yellow/green 状态，并确认图标、窗口可见性、设置持久化和切回功能。
